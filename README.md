# Telecom Industry Analytics Dashboard

## Project Overview
Developed an interactive Power BI dashboard to analyze telecom users, network types (3G/4G/5G), state-wise usage, and operator performance across India.

## Tools Used
- Power BI
- Excel
- DAX
- Data Visualization

## Key Features
- KPI Cards
- Interactive Filters
- State-wise Analysis
- Telecom Operator Comparison
- Network Type Analysis (3G/4G/5G)
- Trend Analysis
